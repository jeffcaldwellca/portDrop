# PortDrop Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A macOS 26 menu-bar app listing listening TCP ports with app icons, open-service links, and an admin-escalating kill button.

**Architecture:** Pure SwiftUI `MenuBarExtra(.window)` app. A `PortMonitor` observable polls `lsof` through `PortScanner`, enriches rows via `ProcessInfoResolver` + `ServiceClassifier`, and `ProcessKiller` terminates processes (direct `kill()` or `osascript ... with administrator privileges`). All logic lives in small files with pure, testable functions.

**Tech Stack:** Swift 6, SwiftUI, macOS 26 SDK (Liquid Glass `.glassEffect`), XcodeGen, XCTest, Developer ID + notarytool.

**Spec:** `docs/superpowers/specs/2026-08-23-portdrop-design.md`

## Global Constraints
- Deployment target macOS 26.0; Swift 6 language mode; strict concurrency.
- No App Sandbox. Hardened Runtime enabled. `LSUIElement = YES` (no Dock icon).
- Bundle id `com.jeffcaldwell.PortDrop`, team `88ZPCYS252`.
- Commit messages: no AI co-author trailers.

### Task 2: Models + PortScanner parser (TDD)
**Files:** `Models/ListeningPort.swift`, `Services/PortScanner.swift`, `PortDropTests/PortScannerTests.swift`.
**Produces:** `struct ListeningPort: Identifiable, Hashable, Sendable { id: String; pid: pid_t; processName: String; user: String; port: UInt16; bindAddress: String; ipVersions: Set<IPVersion> }`, `enum IPVersion { case v4, v6 }`, `enum PortScanner { static func parse(_ output: String) -> [ListeningPort]; static func scan() async throws -> [ListeningPort] }`, `enum ScanError: Error { case lsofFailed(String) }`.
- [ ] Tests (fixtures are real `lsof -F pcLnT` output):
  - IPv4 single: `p123\ncnode\nLjeff\nn*:3000\nTST=LISTEN\n` → 1 port, pid 123, port 3000, bind `*`, v4.
  - v4+v6 twin: `p5\ncpython\nLjeff\nn127.0.0.1:8000\nTST=LISTEN\nn[::1]:8000\nTST=LISTEN\n` → 1 port with `{v4,v6}`.
  - Two processes, root sshd → 2 ports, user `root`.
  - Empty string → [].
  - Sorted by port ascending.
- [ ] Run → fail. Implement parser: iterate lines; `p` starts block (pid), `c` name, `L` user, `n` host:port — split on last `:`; strip `[]` for v6. Merge key `pid:port`.
- [ ] `scan()` runs `Process` `/usr/sbin/lsof -iTCP -sTCP:LISTEN -P -n -F pcLnT`; exit status 1 with empty stdout is "no results" (lsof returns 1 when nothing matched) → []; other failure → `ScanError`.
- [ ] Tests pass. Commit `feat: lsof port scanner`.

### Task 4: ProcessInfoResolver + ProcessKiller
**Files:** `Services/ProcessInfoResolver.swift`, `Services/ProcessKiller.swift`.
**Produces:** `struct ProcessPresentation: Sendable { displayName: String; icon: NSImage; bundlePath: String?; executablePath: String? }`; `@MainActor final class ProcessInfoResolver { func presentation(for port: ListeningPort, kind: ServiceKind) -> ProcessPresentation }` (cached by pid); `enum ProcessKiller { static func kill(pid: pid_t, force: Bool) async throws }`, `enum KillError: Error { case cancelled, failed(String) }`.
- [ ] Resolver: `proc_pidpath` via `Darwin`; find `.app` ancestor in path; `NSRunningApplication(processIdentifier:)` first; else `NSWorkspace.shared.icon(forFile:)`; else `NSImage(systemSymbolName: kind.symbolName)`.
- [ ] Killer: `Darwin.kill(pid, sig)`; `errno == ESRCH` → return; `errno == EPERM` → `osascript -e 'do shell script "/bin/kill -SIGNAME PID" with administrator privileges'`; stderr containing `-128` → `.cancelled`; nonzero → `.failed(stderr)`.
- [ ] Build passes. Commit `feat: process info + killer`.
